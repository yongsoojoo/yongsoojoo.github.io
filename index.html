About the Lab

The Memory & Storage Laboratory (M&S Lab) at Kookmin University investigates how operating systems, device firmware, and hardware should cooperate to get the most out of modern memory and storage devices. Our central theme is I/O completion that adapts dynamically to workload characteristics: deciding, at run time, whether an I/O should be completed by polling, by an interrupt, or by an adaptive hybrid of the two.

Our work spans the full I/O stack — SSD firmware, block layer, kernel I/O path, and virtualized storage — and reaches beyond performance to energy efficiency and security. Results have appeared at top-tier venues including USENIX FAST, ACM HotStorage, HPCA, DAC, and IEEE TC/TCAD, and have been transferred into granted US and Korean patents.

Research Areas

I/O Completion Optimization

Polling, interrupts, and adaptive hybrid polling for high-performance SSDs, switched dynamically under CPU contention.

Virtualized I/O & Storage

Expanding the polled I/O path of the Linux kernel so that virtual machines get low-latency storage access.

Storage Security

Ransomware defense inside the SSD: memory-efficient overwrite detection implemented at the firmware level.

SSD/NVM Performance

Exploiting device-internal parallelism and nonvolatile memory to accelerate application launch and data access.

Energy-Efficient Memory

Co-optimizing performance, energy, and device lifetime across PCM, STT-RAM, flash, and DRAM based systems.
